<h1 align="center">Zen Deck 5.4.2</h1>

<p align="center">
  <strong>Pinned tabs stay put.</strong><br />
  Tabs Zen Deck pins remember the page they open, and agents can pin tabs too.
</p>

## Bug fixes

<details>
<summary><strong>No false "changed" slash on pinned tabs.</strong> Tabs that Zen Deck pins store the page they load as their pinned URL, not <code>about:blank</code>.</summary>

Opening a tab into a folder pinned it while it was still blank. Zen saved that blank page as the pinned URL, so every such tab showed the slash before its title and offered to go back to a page it never had. Zen Deck now waits for the page to load and stores that URL.
</details>

<details>
<summary><strong>Edit and replace clear the slash.</strong> <strong>Edit pinned URL</strong> and <strong>Replace pinned URL with current</strong> update Zen's indicator straight away.</summary>

Before, the stored URL changed but the slash stayed until you browsed somewhere. Replace now also stores the page the tab actually shows. Tabs that already show the slash clear when you use **Replace pinned URL with current** once.
</details>

## For AI agents (MCP)

<details>
<summary><strong>Pin tabs from <code>zen_apply_patch</code>.</strong> Tab nodes take <code>"pinned": true</code> or <code>false</code>.</summary>

New tabs open pinned at a space root, and existing tabs pin or unpin after any move. Tabs in a folder are always pinned, so unpinning one fails unless the patch moves it to a space root. `essential` takes priority over `pinned`. The tool count stays the same.
</details>

The bridge protocol is now version 8. Update the extension and `zen-deck-mcp.mjs` together, or the server reports a version mismatch.

## Install or update

**On 5.4.1:** open the deck and choose **Install now** on the update notice.

**Anywhere else:** download [`zen-deck-v5.4.2-firefox.zip`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.4.2/zen-deck-v5.4.2-firefox.zip) and install it from `about:addons` → ⚙ → **Install Add-on From File…**. Coming from 4.x, see the [5.0.0 notes](https://github.com/SanderCokart/Zen-Deck/releases/tag/v5.0.0) first.

The matching MCP server is [`zen-deck-mcp.mjs`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.4.2/zen-deck-mcp.mjs). Download it again from Settings, since 5.4.1's server cannot talk to 5.4.2.
