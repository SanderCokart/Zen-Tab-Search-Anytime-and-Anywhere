<p align="center">

## Highlights

- **Four complexity presets.** Simple, Enhanced, Pro and Dev, plus Custom when you mix them.
- **First-run setup.** The first `Alt+F` after 5.2 asks how much deck you want. Continue writes it; Settings can change it later.
- **Spotlight.** Simple and Enhanced sit in a centred card. Tabs melt into the same pane as the search field — no glass on glass.
- **Timer swap.** Enhanced and above: the clock key replaces the tab list with every running timer.
- **NOW keys stay on the strip.** The current tab is still ringed in every column. Its copy, timer, todo and status keys live on the top strip; duplicates only show them on hover.
- **A quieter footer.** Tab, space and todo counts are gone. The bar keeps the MCP link and version, or appears only for an update.
- **Wipe extension data.** Two clicks in Settings. Storage and the profile backup both go, so onboarding can run again.

## Complexity, from the first key

5.1 put every surface on the table at once: spaces, essentials, folders, issues, todos, hosts, the status bar. That is still the deck — it is no longer the only deck.

Open the overlay after installing 5.2 and you get a detached **setup card**. The Complexity module on it is the same one that lives at the top of Display options. Pick a preset, or tick features by hand, then **Continue**. The Continue key sits in its own footer, clear of the scroll track.

Until you continue, the overlay stays on that card. After that, `Alt+F` opens the deck you chose.

The **Complexity** slider has four stops. Moving it overwrites the checkboxes. Ticking a box off a preset turns the meta to **Custom**; the slider sits on the nearest named stop so you can snap back.

Cosmetic controls — theme, colours, type size, density, gaps, sound — are not on this slider. They stay where you left them.

**To-dos** and the **issue navigator** need a second column, so they cannot sit in Spotlight. Turn either on and fullscreen comes with it. Turn fullscreen off and both go out.

`!` and `#` still filter the tab list on every preset. You do not need the navigator column to jump to a pull request.

Coming from **5.1.0:** the first open after 5.2 is this setup. Continue on Simple puts you on Spotlight. Pick **Pro** or **Dev** if you want the full rack you already had.

### Simple — search, and nothing in the way

Simple hides spaces, essentials, copy, timers, folders, the context menu, todos, status colours, MCP, hosts, the issue column and the status bar. The overlay is a **Spotlight** card over the page: search field, settings key, and a tab list that shares the same surface.

The current tab is ringed and tagged **NOW**. Prefixes still work. Type `!` and the list is only merge requests and pull requests; `#` is only issues. No extra column, no extra chrome.

![Simple, with ! keeping only pull and merge requests](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-simple-forge.png)

*`!` in Simple. The navigator column is a Dev stop; the filter is not.*

### Enhanced — the same card, with hands

Enhanced stays on Spotlight and turns the lights on: spaces and essentials come back, copy link and timers land on the row, and an already-open tab is reused when another app asks for the same address.

The header grows a **clock key**. Press it and the tab list is replaced by every running timer: a large NEXT readout, then each countdown with Edit and Clear. Press it again and the tabs return. Spotlight has no room for a dock, so the list *is* the dock, on demand.

### Pro — the two-column rack

Pro fills the window. Folder groups, the in-omnibar context menu, traffic-light status, the todo column, the `@` prefix, the MCP module in Settings, and a persistent status bar all come on.

The NOW strip sits above the columns with the current tab's actions on it. Todos fill the right-hand pane. Running timers sit under them as a **dock**: the soonest on a large LCD, then the next two upcoming. The clock key still swaps the overlay for the full list when you have more than three. Collapse all still folds a column; the current tab still peeks out of a folded group.

![Pro: fullscreen tabs and todos, with the NOW strip along the top](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-pro.png)

### Dev — the whole instrument

Dev is Pro plus the GitHub and GitLab navigator and host overrides. Three columns: tabs, issues and requests, todos. Kind chips, Recent, the hosts key, the per-tab proxy — the deck 5.1 put on every session, now a stop you choose. Click the **project name** in the navigator to open that repository; the chevron still folds the group.

![Dev: tabs, the issue navigator, and todos across the window](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-dev.png)

## Spotlight is one pane

Fullscreen still uses nested cards for its full-bleed columns. Spotlight does not. The tab results sit on the same chassis as the search field, so the inner radius no longer stacks on the outer one. Over a live page the card reads as one piece of glass, not a card in a card.

## The current tab, without a halo of keys

5.1 tagged the current tab **NOW** in the list and the issue navigator. 5.2 takes that through essentials, folders, the navigator and the todo column: wherever the tab you are on appears, it is ringed.

Its **quick actions do not**. Copy, timer, todo and status stay on the **NOW strip** at the top of the fullscreen deck. A duplicate of that tab in another section keeps the ring and the tag, and shows its keys the way every other row does: on hover, or when you rest on it. Selected-but-current no longer forces the keys open, so opening the overlay does not light up a second toolbar on the row you are already looking at.

## Search ink, sitting in the LCD

The query field shares a readout with **GOOGLE** and **SEARCH**. Capital labels sit on the cap-height; lowercase query text sat a hair low in Firefox, so `gitlab` looked dropped against the legends.

The query is lifted a fraction of an em so mixed-case ink shares the optical centre of the LCD. The labels did not move. The letters did.

## A footer that earns its row

The status bar used to count tabs, essentials, spaces, issues, todos and running timers. Those numbers duplicated what the columns already say.

They are gone. With the **Status bar** switch on (Pro and Dev), the row is an MCP link on the left and the version on the right. With it off, the bar is absent — unless an update is waiting, in which case Simple and Enhanced still get the notice, so you can install in place without turning the rest of the chrome back on.

![MCP link on the left, version and Check for updates on the right](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/status-bar.png)

## Wipe, and start again

Uninstalling a Firefox add-on does not always take the profile backup with it. Zen Deck mirrors settings into that file so a temporary install can come back. The side effect: delete the add-on, reinstall, and onboarding may not run, because the backup still says you finished it.

**Settings → Data → Wipe extension data** is a two-step key. The first press arms it. The second — **Wipe now — cannot be undone** — clears `storage.local` and the profile backup, then reloads the extension. The next `Alt+F` is the setup card again.

This is for a clean slate, not for switching presets. Presets are the Complexity slider.

## Also in 5.2

- **Toolbar button.** A leftover popup URL could swallow the click. The button now clears that and opens the same overlay as `Alt+F`, Spotlight or fullscreen according to your preset.
- **Todo rows** mark the current tab with NOW, same ring as the tab list.
- **Filled todo key** on the strip, so the action reads as a control rather than an outline.

## Fixes

- **Timer dock on fullscreen.** Pro and Dev show the soonest timer and the next two under the todos again. The clock key still swaps in the full list. Spotlight keeps timers behind that key, so the card does not grow a dock.
- **Card shadows.** Pane overflow no longer clips the drop shadow along the bottom of the tabs, issues, todos and timer cards.
- **Square fullscreen.** The outer chassis meets the window with no radius. Spotlight and the first-run card keep their rounded corners.
- **Open the project.** In the issue navigator, the GitHub or GitLab project name opens that repository. If the homepage is already a tab, it switches to it. The chevron still folds the group.

## Install or update

**On 5.1.0:** open the deck and choose **Install now** on the update notice.

**Anywhere else:** download [`zen-deck-v5.2.0-firefox.zip`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.2.0/zen-deck-v5.2.0-firefox.zip) and install it from `about:addons` → ⚙ → **Install Add-on From File…**. Coming from 4.x, see the [5.0.0 notes](https://github.com/SanderCokart/Zen-Deck/releases/tag/v5.0.0) first.

The matching MCP server is [`zen-deck-mcp.mjs`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.2.0/zen-deck-mcp.mjs).
