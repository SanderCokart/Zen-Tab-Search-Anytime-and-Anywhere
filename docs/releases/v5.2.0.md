<h1 align="center">Zen Deck 5.2: Dial in the deck</h1>

<p align="center">
  <strong>Dial in the deck.</strong><br />
  Simple is compact. Dev is the whole rack. You pick the stop.
</p>

## Highlights

- **Four complexity presets.** Simple, Enhanced, Pro and Dev, plus Custom when you mix them.
- **Onboarding.** The first `Alt+F` after 5.2 asks how much deck you want. Continue saves it. Settings can change it later.
- **Compact overlay.** Simple and Enhanced sit in a centred card over the page: search and tabs on one surface.
- **Timer swap is back.** Enhanced and above: the clock key replaces the tab list with every running timer, so the compact overlay can still use timers.
- **The current tab.** It is ringed in every column. In fullscreen, copy, timer, todo and status live on the strip at the top.
- **A quieter footer.** Tab, space and todo counts are gone. The bar keeps the MCP link and version, or shows only when an update is waiting.
- **Wipe extension data.** Two clicks in Settings. Onboarding can run again.

## Four complexity presets

5.1 showed every surface at once. That deck is still here. It is no longer the only one.

The **Complexity** slider has four stops. Moving it writes the checkboxes. Mix them by hand and the meta becomes **Custom**. Theme, colours, type size, density, gaps and sound stay where you left them.

**To-dos** and the **issue navigator** need a second column, so they live in fullscreen. Turn either on and fullscreen comes with it. Turn fullscreen off and both go out.

`!` and `#` still filter the tab list on every preset. You do not need the navigator column to jump to a pull request.

Coming from **5.1.0:** the first open after 5.2 is onboarding. Continue on Simple for the compact overlay. Pick **Pro** or **Dev** if you want the full rack you already had.

## Onboarding

Open the overlay after installing 5.2 and you get an onboarding menu. Pick a preset, or tick features by hand, then **Continue**. After that, `Alt+F` opens the deck you chose. Change it later in Display options.

## Compact overlay

Simple and Enhanced sit in a centred card over the page. Search, settings, and the tab list share that card.

Simple is search and a list of tabs. Prefixes still work. Type `!` and the list is only merge requests and pull requests. `#` is only issues.

![Simple, with ! keeping only pull and merge requests](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-simple-forge.png)

*`!` in Simple. The navigator column is a Dev stop. The filter is not.*

Enhanced stays compact and turns more of the deck on: spaces and essentials, copy link, timers, and reusing an already-open tab.

![Enhanced compact overlay, with spaces, essentials, and copy and timer keys](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-enhanced.png)

## Timer swap is back

Timer swap existed in older versions. It is back so Enhanced can keep timers while staying compact.

Press the **clock key** and the tab list is replaced by every running timer: a large NEXT readout, then each countdown with Edit and Clear. Press it again and the tabs return.

On Pro and Dev the same key still opens the full list. Running timers also sit in a **dock** under the todos: the soonest on a large LCD, then the next few upcoming.

![The clock key swapping the list for every running timer](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-enhanced-timers.png)

*Enhanced. The clock LED tells you timers are running. The key takes you to them.*

## The current tab

Wherever the tab you are on appears (essentials, folders, the navigator, todos), it is ringed.

In fullscreen, copy, timer, todo and status live on the **strip** above the columns, not as a second toolbar on every copy of that row.

![Pro: fullscreen tabs and todos, with the current tab on the top strip](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-pro.png)

Pro fills the window: folders, the in-omnibar context menu, status colours, the todo column, `@`, MCP in Settings, and a status bar.

Dev is Pro plus the GitHub and GitLab navigator and host overrides. Three columns: tabs, issues and requests, todos. Click the **project name** in the navigator to open that repository.

![Dev: tabs, the issue navigator, and todos across the window](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/concept-dev.png)

## A quieter footer

The status bar no longer counts tabs, spaces, issues, todos or timers. Those numbers already live in the columns.

With **Status bar** on (Pro and Dev), the row is an MCP link on the left and the version on the right. With it off, the bar is gone unless an update is waiting. Simple and Enhanced still get that notice so you can install in place.

![MCP link on the left, version and Check for updates on the right](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.2.0/docs/screenshots/dark/status-bar.png)

## Wipe extension data

**Settings → Data → Wipe extension data** is two clicks. The first press arms it. The second clears settings and the profile backup, then reloads the extension. The next `Alt+F` is onboarding again.

Use this for a clean slate, not for switching presets. Presets are the Complexity slider.

## Features

<details>
<summary><strong>Complexity presets.</strong> Simple, Enhanced, Pro, Dev, and Custom when you mix the switches.</summary>

The slider writes a named stop. Tick boxes off a stop and the meta becomes Custom. Cosmetic controls stay independent of the slider.
</details>

<details>
<summary><strong>Onboarding.</strong> First <code>Alt+F</code> after 5.2 asks how much deck you want.</summary>

Continue saves the choice. Display options can change it later. Wipe extension data is how you see onboarding again.
</details>

<details>
<summary><strong>Compact overlay.</strong> Simple and Enhanced sit in a centred card. Pro and Dev fill the window.</summary>

To-dos and the issue navigator need fullscreen. <code>!</code> and <code>#</code> still filter the tab list on a compact overlay.
</details>

<details>
<summary><strong>Timer swap.</strong> The clock key replaces the tab list with every running timer.</summary>

This is the older swap, brought back so Enhanced can use timers without a dock. Pro and Dev keep the dock under the todos and still use the same key for the full list.
</details>

<details>
<summary><strong>Current tab.</strong> Ringed in every column. Fullscreen actions sit on the top strip.</summary>

Essentials, folders, the navigator and todos all mark the tab you are on. Copy, timer, todo and status on that strip are the actions for it.
</details>

<details>
<summary><strong>Click the project.</strong> In the issue navigator, the GitHub or GitLab project name opens that repository.</summary>

If the project homepage is already a tab, it switches to it.
</details>

<details>
<summary><strong>Quieter status bar.</strong> Counts are gone. MCP link and version remain, or the bar appears for an update.</summary>

Pro and Dev can keep the bar on. Simple and Enhanced still see an update notice so you can install in place.
</details>

<details>
<summary><strong>Wipe extension data.</strong> Two clicks in Settings start you on onboarding again.</summary>

It clears stored settings and the profile backup, then reloads. Switching presets does not need a wipe.
</details>

<details>
<summary><strong>Toolbar button.</strong> Opens the same overlay as <code>Alt+F</code>.</summary>

Compact or fullscreen follows the preset you chose.
</details>

## Bug fixes

<details>
<summary><strong>Toolbar click.</strong> The button opens the overlay instead of doing nothing.</summary>

A leftover popup URL could swallow the click. It is cleared, so the button matches <code>Alt+F</code>.
</details>

<details>
<summary><strong>Timer dock on fullscreen.</strong> Pro and Dev show the soonest timer and the upcoming ones under the todos again.</summary>

The clock key still swaps in the full list. Compact overlay keeps timers behind that key.
</details>

<details>
<summary><strong>Folder counts.</strong> Tab counts on folder headings stay clear of the scrollbar.</summary>

Overlay scrollbars no longer paint over the number at the end of the row.
</details>

## Cosmetic changes

<details>
<summary><strong>One surface on the compact overlay.</strong> Tabs sit on the same card as the search field.</summary>

Fullscreen still uses nested cards for its columns. The compact overlay does not stack a second card inside the first.
</details>

<details>
<summary><strong>Square fullscreen.</strong> The outer edge meets the window with no rounding.</summary>

The compact overlay and onboarding keep their rounded corners.
</details>

<details>
<summary><strong>Card shadows.</strong> Drop shadows along the bottom of the panes are no longer clipped.</summary>

Tabs, issues, todos and the timer dock keep their shadow.
</details>

<details>
<summary><strong>Current-tab keys.</strong> A duplicate of the current tab does not force its row keys open.</summary>

Those keys still appear on hover, the way every other row does. The strip at the top holds the actions for the tab you are on.
</details>

<details>
<summary><strong>Filled todo key.</strong> On the strip, the todo action reads as a control.</summary>

It matches the other keys on that strip instead of sitting as an outline.
</details>

<details>
<summary><strong>Search field in the LCD.</strong> Mixed-case query text lines up with the engine and Search labels.</summary>

Lowercase letters in the query sit on the same optical line as the legends beside them.
</details>

## Install or update

**On 5.1.0:** open the deck and choose **Install now** on the update notice.

**Anywhere else:** download [`zen-deck-v5.2.0-firefox.zip`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.2.0/zen-deck-v5.2.0-firefox.zip) and install it from `about:addons` → ⚙ → **Install Add-on From File…**. Coming from 4.x, see the [5.0.0 notes](https://github.com/SanderCokart/Zen-Deck/releases/tag/v5.0.0) first.

The matching MCP server is [`zen-deck-mcp.mjs`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.2.0/zen-deck-mcp.mjs).
