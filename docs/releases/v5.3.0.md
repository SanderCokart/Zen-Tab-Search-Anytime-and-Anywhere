<h1 align="center">Zen Deck 5.3</h1>

<p align="center">
  <strong>Put things in order.</strong><br />
  Fold open issue tabs into folders, drag your todos into place, and sort issues by number.
</p>

## Highlights

- **Organize issue tabs.** One key in the issue navigator turns the tabs you have open into Zen folders, grouped by project.
- **Drag to reorder todos.** Grab a todo anywhere on the row and drop it where you want it. The order sticks.
- **Four ways to sort issues.** Ascending, Descending, Most recent and Least recent, from a menu in the column header. Issue number is the new default.
- **No flash on open.** Your folded folders and todo order are read before the first frame, so nothing jumps after `Alt+F`.

![The organize menu with a folder preview, next to the issue navigator](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.3.0/docs/screenshots/dark/organize-issue-tabs.png)

## Organize issue tabs

The issue navigator already groups what you have open by project, issues and requests. The new **Organize** key, to the right of **All / Issues / MRs**, makes Zen match it.

Pick how you want the folders:

- **As in this list.** Project, then **Issues** or **MRs / PRs**, then the target branch. The folders mirror the navigator.
- **Group with issues.** Each merge or pull request moves next to the issue it belongs to, under the project. It reads the related issue from the request's label, so a request without that label stays under its target branch.

Rest the pointer on an option and a small printout to the left of the menu draws the folder tree it will make. Folders that already exist are reused by name. Essential tabs are never moved.

A prompt asks before anything moves. Tick **Don't ask this again** on it, or turn off **Confirm before organizing issue tabs** in Display options, to skip it later.

![Hovering both options, then confirming Group with issues](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.3.0/docs/gifs/organize-tabs.gif)

*Both previews, then the confirm prompt.*

> [!NOTE]
> Zen pins a tab when it enters a folder. That is Zen's own rule and Zen Deck does not change it.

## Drag todos into order

Todos keep the order you give them. Press anywhere on a row and move it; a plain click still opens the tab. **Mark as done** and the status key keep their own clicks. While you filter the search, dragging is off so a partial list cannot reorder the whole one.

![Dragging the last todo to the top](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.3.0/docs/gifs/todo-reorder.gif)

*Drag the last todo to the top. Reopen the deck and it is still there.*

## Sort issues your way

The old toggle between recent and old is now a menu in the **Issues and requests** header with four choices: **Ascending**, **Descending**, **Most recent** and **Least recent**. Number sorting runs on the issue or request number, and ties fall back to the most recently opened.

The default changed to **Ascending**. Sorting by last opened kept putting the tab you had just left at the top of the list.

![Switching through the four sort modes](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.3.0/docs/gifs/issue-sort.gif)

*Descending, Ascending, Least recent, Most recent.*

## Features

<details>
<summary><strong>Organize issue tabs.</strong> A key in the navigator creates Zen folders from your open issue, merge request and pull request tabs.</summary>

Two layouts: **As in this list** and **Group with issues**. A hover preview shows the folder tree first. A confirm prompt can be turned off in Display options.
</details>

<details>
<summary><strong>Drag to reorder todos.</strong> Move a todo from anywhere on its row.</summary>

The order is stored and survives restarts. The current tab keeps its place in the list instead of jumping to the top.
</details>

<details>
<summary><strong>Issue sort menu.</strong> Ascending, Descending, Most recent, Least recent.</summary>

Replaces the two-way toggle. Ascending by number is the default.
</details>

<details>
<summary><strong>Confirm before organizing issue tabs.</strong> A switch in Display options.</summary>

On by default. It is greyed out while forge detection is off, since there are no issue tabs to organize.
</details>

## Bug fixes

<details>
<summary><strong>Open without a jump.</strong> Folded folders and todo order are applied on the first frame.</summary>

They used to load a moment after the omnibar appeared, so sections could pop open or rows could shuffle. The overlay now waits for the stored state before it draws.
</details>

<details>
<summary><strong>Sorting by number.</strong> Ids compare as numbers, and anything that is not a plain number falls back to a natural text sort.</summary>

So <code>9</code> comes before <code>10</code>, not after it.
</details>

## Cosmetic changes

<details>
<summary><strong>Organize key.</strong> A square key with a boxes icon, sized to the other keys in the row.</summary>

It sits beside the filters and has a tooltip legend like the rest of the keys.
</details>

<details>
<summary><strong>Sort menu in the header.</strong> A key-styled select with the arrow on the right replaces the text toggle.</summary>

It uses the same colour as the other header readouts, with the count after it.
</details>

<details>
<summary><strong>Hover preview.</strong> The folder tree prints on an LCD card.</summary>

It sits to the left of the menu and does not catch the pointer, so moving between options does not flicker.
</details>

## Install or update

**On 5.2.1:** open the deck and choose **Install now** on the update notice.

**Anywhere else:** download [`zen-deck-v5.3.0-firefox.zip`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.3.0/zen-deck-v5.3.0-firefox.zip) and install it from `about:addons` → ⚙ → **Install Add-on From File…**. Coming from 4.x, see the [5.0.0 notes](https://github.com/SanderCokart/Zen-Deck/releases/tag/v5.0.0) first.

The matching MCP server is [`zen-deck-mcp.mjs`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.3.0/zen-deck-mcp.mjs).
