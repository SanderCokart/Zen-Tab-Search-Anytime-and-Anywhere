## Changes

- **MCP server from GitHub.** Settings downloads the MCP server that matches your Zen Deck version from its GitHub release, instead of shipping it inside the add-on. The add-on gets smaller. If the download fails, Settings links the release page so you can grab it by hand.
- **Settings opens on your own settings.** The Settings page waits for storage before it paints, so it no longer flashes the defaults (for example Simple with spaces showing) before your choices land.
- **Snappier typing with `-word`.** Excluding matches no longer re-reads every tab's title, folder and host on each keystroke, and the issue navigator groups its entries once per change instead of three times.
- **Faster `Alt+F`.** The omnibar starts opening while the transition setting is still being read.
- **Copy in Settings falls back.** Copying the MCP token or config now works where the clipboard API is refused, like the omnibar's copy already did.
- **Under the hood.** Shared tooltip, dropdown, confirm and dialog pieces replace several hand-copied versions, and a leftover prototype was removed. Nothing should look different.
