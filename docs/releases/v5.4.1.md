<h1 align="center">Zen Deck 5.4.1</h1>

<p align="center">
  <strong>A lighter add-on.</strong><br />
  The MCP server comes from GitHub, Settings opens on your own values, and typing stays quick.
</p>

## Features

<details>
<summary><strong>MCP server from its release.</strong> <strong>Download MCP server</strong> in Settings fetches <code>zen-deck-mcp.mjs</code> from the GitHub release that matches your Zen Deck version.</summary>

The server no longer ships inside the add-on, so the add-on is smaller. The bridge only accepts a server from the same release, so Settings always fetches that version, not the latest one. If the download fails, Settings says so and links the release page so you can save the file by hand.
</details>

<details>
<summary><strong>Quicker typing with <code>-word</code>.</strong> Hiding matches no longer re-reads every tab on each keystroke.</summary>

The title, folder and host that a <code>-word</code> checks are prepared once per tab list. The issue navigator also sorts and groups its entries once per change instead of three times. Results are the same.
</details>

<details>
<summary><strong>Quicker <code>Alt+F</code>.</strong> The deck starts opening while the transition setting is still being read.</summary>

The two used to run one after the other. The transition you picked still plays.
</details>

## Bug fixes

<details>
<summary><strong>Settings opens on your values.</strong> The Settings page waits for your stored settings before it draws anything.</summary>

It used to paint the defaults for a moment, for example spaces showing on Simple, and then jump to your choices.
</details>

<details>
<summary><strong>Copy in Settings.</strong> <strong>Copy token</strong> and <strong>Copy MCP config</strong> work when Firefox refuses the clipboard API.</summary>

They now use the same fallback as copying a link in the deck. Before, the copy failed without a word.
</details>

## Under the hood

Tooltips, dropdown menus, confirm prompts and the rename and pinned-URL dialogs each share one component now, instead of several hand-made copies. A leftover design prototype is gone. Nothing should look or behave differently. If something does, open an issue.

## Install or update

**On 5.4.0:** open the deck and choose **Install now** on the update notice.

**Anywhere else:** download [`zen-deck-v5.4.1-firefox.zip`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.4.1/zen-deck-v5.4.1-firefox.zip) and install it from `about:addons` → ⚙ → **Install Add-on From File…**. Coming from 4.x, see the [5.0.0 notes](https://github.com/SanderCokart/Zen-Deck/releases/tag/v5.0.0) first.

The matching MCP server is [`zen-deck-mcp.mjs`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.4.1/zen-deck-mcp.mjs).
