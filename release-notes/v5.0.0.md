<h1 align="center">Zen Deck 5.0</h1>

<p align="center">
  <b>Zen Tab Search is now Zen Deck</b>: a rebuilt omnibar with a hardware feel, light and dark themes, interface sounds, and a long list of new tools for folders, pinned tabs and timers.
</p>

![The dark omnibar with spaces, nested folders, issues, todos and the timer dock](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.0.0/docs/screenshots/dark/search-omnibar.png)

> [!IMPORTANT]
> **Upgrading from 4.x?** The rename came with a new add-on ID, so 4.x can't update to 5.0.0 on its own. Download [`zen-deck-v5.0.0-firefox.zip`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.0.0/zen-deck-v5.0.0-firefox.zip) and install it from `about:addons` → ⚙ → **Install Add-on From File…**. Your settings come back from the profile backup. The [installation guide](https://github.com/SanderCokart/Zen-Deck/blob/v5.0.0/README.md#installation) lists the Zen preferences it needs. From 5.0.0 on, updates install in place from the deck.

## Highlights

- **A new interface**, modelled on [Shu Ding's SPEC-01](https://github.com/shuding/spec-01): raised keys, recessed wells, LED indicators and LCD readouts.
- **Light, dark and System themes**, each with its own palette you can recolour.
- **Interface sounds**: clicks, ticks and chimes recorded from the SPEC-01 hardware kit.
- **Folders that behave like folders**: nested, collapsible, and one click to fold a whole column.
- **Pinned and essential tabs you can edit**: change the restore URL without leaving the page you're on.
- **A timer dock** that keeps your next three deadlines in view.
- **A smaller MCP server**: 35 tools merged into 17, plus new tools for pinned URLs.

## The redesign

Every surface was rebuilt from the same parts: the omnibar, menus, dialogs, the timer form and Display options. Keys look like they can be pressed, settings sit in recessed wells, and running timers read out on an LCD. Inter and IBM Plex Mono now ship with the extension, so the deck looks the same on every machine.

Display options works like a rack of modules: dials, sliders and switches, and every change applies as you make it.

![The Theme module with System, Light and Dark, and the four colour keys](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.0.0/docs/screenshots/theme-colors.png)

### Colour, opacity and size

- **Four colour keys** (accent, frame, panels and text) start on AUTO and follow the theme. Light and dark keep separate custom palettes, and each key resets on its own.
- **Background opacity** fades the panels so the page behind shows through, from 0% to 100%. Text, keys and readouts stay solid.
- **Ctrl + mouse wheel** over the omnibar changes the font size one pixel per notch.
- Font size, density and the gap sliders control how much fits on screen.

![A warm custom palette on the dark omnibar](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.0.0/docs/screenshots/dark/display-colors.png)

### Sound

Typing, renaming, setting a timer and finishing a todo each have their own sound. Marking a todo done plays a longer note, and clearing the column plays a short success chime. Sounds are on by default. The **Sound** module has a volume dial, **Click**, **Tick** and **Chime** keys to preview each one, and a switch to turn them all off.

![The Sound module with its volume dial, switch and preview keys](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.0.0/docs/screenshots/sound-settings.png)

## The omnibar

- **The NOW strip** under the search field shows the tab you're on, with its status, timer and todo keys. Click the strip to return to that tab.
- **Tab keys** for close, rename, todo, timer and hosts slide in when the pointer rests on a row, and stay put as you move along it.
- **The tab context menu** now replaces Zen's own on right-click. Close, rename, folder moves, status, todo, timer, host overrides and the pinned-URL actions are all in one place.
- **The issue navigator** can take merge and pull requests on their own, separately from issues.
- **Lighter rendering**: the full-window backdrop blur is gone; a scrim still dims the page.

## Folders

Zen's nested folders now show as nested groups in the deck, and each one folds on its own. **Collapse all** on the Tabs and the Issues headers folds the whole column, then becomes **Expand all**. A folded folder still shows your current tab, and a search finds matches inside folded folders too.

**Move to folder** lists every destination as `Space · Parent / Folder` and marks the folder the tab is already in. **Remove from folder** takes it out again.

## Pinned and essential tabs

Zen stores a restore address for every pinned and essential tab, and until now you could only change it by navigating there. **Edit pinned URL** lets you type a new one, and **Replace pinned URL with current** saves the page the tab is showing now. Essential tabs, which Zen won't let you rename, keep the names you give them in the deck, and search matches those names.

![The Edit pinned URL dialog](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.0.0/docs/screenshots/pinned-url.png)

## Timers and todos

The **timer dock** at the bottom of the omnibar shows the next timer to finish as a large LCD countdown, with the two after it listed underneath. Each one has **Edit** and **Clear** keys. Countdowns longer than an hour show days, hours and minutes. Todos fill the space above the dock and scroll when the list gets long.

The timer form now fits in a tab window. Its **When** field still takes plain language like `45m`, `tomorrow at 9am` or `friday at 5pm`, and **Ends at** shows the result before you press **Set**.

![Typing friday at 5pm fills in the end time](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.0.0/docs/screenshots/timer-natural-language.png)

## For AI agents (MCP)

The MCP server went from 35 tools to **17**. Layout changes go through **`zen_apply_patch`**, which creates, renames and moves spaces, folders and tabs in one tree, and that includes renaming essentials. **`zen_get_pinned_url`** and **`zen_set_pinned_url`** are new. Timers, todos, colours, closing and forge labels keep their own tools. The Google Workspace tools are gone, so the server is only about Zen.

Get [`zen-deck-mcp.mjs`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.0.0/zen-deck-mcp.mjs) and follow the [setup guide](https://github.com/SanderCokart/Zen-Deck/blob/v5.0.0/mcp/README.md#install).

## Also in this release

- The toolbar popup is gone. `Alt+F` opens the omnibar everywhere, including Zen's built-in pages.
- Release zips are built with debug logging off.
