<h1 align="center">Zen Deck 5.1</h1>

<p align="center">
  The omnibar now reaches the web, every key tells you what it does, and the deck opens straight to your last session.
</p>

## Highlights

- **Web search from the omnibar.** `Shift+Enter` opens a site or searches the web, with seven engines to pick from.
- **Hardware tooltips.** Rest on a key and its name prints out on a small LCD, letter by letter.
- **Copy link** on every tab, from its row or its menu.
- **You are here.** The current tab is ringed and tagged **NOW** in every column, even inside a folded folder.
- **Padding to gap ratio.** One dial decides whether spacing goes between rows or inside them.
- **Instant `Alt+F`.** The omnibar shows your last session on the first frame, then refreshes.
- **Less to maintain.** The toolbar popup and its settings are gone; the toolbar button opens the omnibar.

## Search the web without leaving the deck

The search field now starts with an engine: Google, DuckDuckGo, Bing, Brave, Kagi, Startpage or Ecosia. Pick one once and it stays picked.

`Enter` still searches your tabs. `Shift+Enter` takes the query to the web, in a new tab:

- **Sites open directly.** `github.com/zen-browser`, `localhost:3000` and `192.168.1.10` go straight to the address.
- **Everything else is searched.** Words, questions and filenames like `main.ts` go to your engine.
- **Start with `?`** to search for something that looks like a site, such as `?youtube.com`.

![The engine menu at the left of the search field](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.1.0/docs/screenshots/dark/web-search.png)

## Tooltips with a printout

Every key now has a legend. Rest the pointer on it and the name prints onto an LCD above it, one letter at a time, with a soft tick per letter when sounds are on. A short delay keeps the legends quiet while you sweep down the list.

Tab titles that are cut off show in full the same way. Titles that already fit get no tooltip.

The menus, dialogs, checkboxes, text fields, colour picker and scrollbars were rebuilt in the same hardware style, so everything you click now looks like it belongs to the deck.

![Copy link's legend above a tab row](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.1.0/docs/screenshots/dark/tooltip.png)

## Copy link

Each tab row has a **Copy link** key, and the tab menu has a **Copy link** item. Both put the tab's address on the clipboard. Handy for pasting a merge request into chat without switching to it first.

## The current tab, wherever it is

The tab you're on is ringed and tagged **NOW** in the tab list and in the issue navigator. Fold its folder or project and it still peeks out, alone, so you never lose track of where you are. The current issue also stays in its project group in the navigator instead of being moved out of it.

![The omnibar with the current pull request tagged NOW in the issue navigator](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.1.0/docs/screenshots/dark/search-omnibar.png)

## Padding to gap ratio

The **Gaps** module, now listed in the same order as the omnibar, sets the space between each kind of neighbour. The new **Padding to gap ratio** dial decides how that space is used. At **1** it is split evenly. Turn it down and it becomes gap between the elements. Turn it up and it becomes padding inside them, so rows and sections get roomier without drifting apart.

![The Gaps module with a slider per neighbour and the ratio dial](https://raw.githubusercontent.com/SanderCokart/Zen-Deck/v5.1.0/docs/screenshots/dark/gap-settings.png)

## Faster to open

`Alt+F` used to wait for fresh tab data before the omnibar appeared. It now opens on the first frame with your last session's tabs and settings, and swaps in the fresh data a moment later. Fonts also load from the files bundled with the extension, with no second copy and no fallback format.

## Removed

5.0 kept some legacy code around. 5.1 removes it:

- **The toolbar popup.** Clicking the toolbar button now opens the omnibar, the same as `Alt+F`. The `Open Zen Deck popup` shortcut is gone with it.
- **The popup's "hide spaces" and "hide essential tabs" switches.** The omnibar's own switches still work.
- **"Follow the page zoom level".** The omnibar always keeps the same size, whatever the zoom level of the page behind it.

## Fixes

- **Essential tabs**: a lone essential fills the row, and the address no longer squeezes titles like *Substack* down to *Su…*.
- **Search engine menu**: it stays solid at any background opacity, like the other menus.
- **Keys and hit areas**: pressed keys keep their full click area.
- **MCP server**: [`zen-deck-mcp.mjs`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.1.0/zen-deck-mcp.mjs) is minified and bundles one copy of Zod instead of two, so it's down from 1.3 MB to 595 KB.
- **Logo**: the icon now has a transparent background.

## Install or update

**On 5.0.0:** open the deck and choose **Install now** on the update notice in the status bar.

**Anywhere else:** download [`zen-deck-v5.1.0-firefox.zip`](https://github.com/SanderCokart/Zen-Deck/releases/download/v5.1.0/zen-deck-v5.1.0-firefox.zip) and install it from `about:addons` → ⚙ → **Install Add-on From File…**. Coming from 4.x, see the [5.0.0 notes](https://github.com/SanderCokart/Zen-Deck/releases/tag/v5.0.0) first.
